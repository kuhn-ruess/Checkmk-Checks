# Palo Alto XML API Monitoring

Special agent that queries a Palo Alto Networks firewall through its PAN-OS XML API. Monitors certificates, IPSec tunnels and IKE gateways (state and cipher), system info, sessions, CPU, environment, high availability, interfaces, BGP/OSPF neighbors and licenses. The collected topics are selectable per rule.
